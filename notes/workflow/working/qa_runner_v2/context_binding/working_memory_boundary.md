# Working Memory Boundary

## Session Working Memory 的角色

`Session Working Memory` 是：

- short-term semantic memory
- execution continuity layer
- relevant set 的候选来源之一

## 它不是什么

它不是：

- referent truth source
- 唯一 target owner
- 保证 query 所指一切对象都在其中的系统

## Context Binding 和 Working Memory 的关系

`ContextBindingPower` 不负责存 memory。

它负责：

- 读取 recent conversation
- 读取 working memory candidates
- 读取 registry / memory anchors
- 产出 relevant set

也就是说：

- working memory 是候选池的一部分
- 不是 binding 的唯一依据
