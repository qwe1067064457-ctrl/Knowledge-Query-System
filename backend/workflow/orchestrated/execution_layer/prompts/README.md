# execution_layer prompts

## 职责

这里放 execution layer 的规则说明与结果投影说明。

## 本质作用

这些文档的本质作用，是把 execution layer 的状态机与结果口径沉淀成可读说明，避免实现与理解脱节。

## 放什么

- execution layer rules
- execution result projection notes

## 不放什么

- 不放 planner prompt
- 不放主回答系统 prompt

## 与相邻层的边界

- 供开发者与后续 owner 对齐 execution layer 口径
